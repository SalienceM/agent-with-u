# Tasks

## 1. 时间规则与持久数据

- [x] 1.1 实现普通 Session 定时配置的数据模型、版本及校验，包含单次/每日/每周/固定间隔、时区、错过策略和启用状态；通过合法配置往返及空指令、非法时间、非普通 Session 的拒绝测试验证。
- [x] 1.2 实现与预览共用的时间计算器，覆盖一分钟最短间隔、固定 UTC 锚点、时钟回拨/前跳、60 秒宽限和禁用后重新启用；使用可控时钟验证下一次时间、合并次数及单次耗尽后原实例仍可执行。
- [x] 1.3 纳入目标平台所需的 IANA 时区数据及冻结分发配置；以跨时区、DST 缺失/重复时刻、单次 offset 选择和缺失时区数据测试验证，不运行生产打包发布。
- [x] 1.4 新增 owner/executor/Session 范围的 SQLite 计划、触发和请求回执存储，支持 CAS、唯一触发键、到期索引及消费游标；在隔离临时目录验证重开恢复、相同请求去重、不同意图拒绝、修订冲突及跨身份不可见。
- [x] 1.5 实现有界后台存储队列、分页历史和保留去重依据的归档；通过人为持锁/写失败及大量历史 fixture 验证事件循环仍可处理状态和停止请求，清理不会重放旧时点。
