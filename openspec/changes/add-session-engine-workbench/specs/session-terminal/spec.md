# Spec Delta

## Purpose

为工程会话提供位于真实执行节点的交互终端，让用户在明确的工作目录与权限下运行和检查项目。终端进程、窗口展示和会话执行彼此区分，连接恢复不重复执行命令，停止只有在确认进程退出后才完成，并遵守现有 LOOP 控制权边界。

## ADDED Requirements

### Requirement: 用户显式创建绑定会话身份的终端

系统 SHALL 在 Engine 中提供集成终端区域，支持用户显式创建交互式终端并显示用户、执行节点、初始工作目录、Shell 和运行状态。进入模式、打开区域、切换窗口或加载项目 MUST NOT 自动创建终端、发送命令或运行项目；终端 SHALL 在会话实际执行节点运行，而非 Relay 或错误的控制端。

#### Scenario: 打开区域后创建终端
- **WHEN** 用户展开空终端区域，再点击创建终端
- **THEN** 展开本身不启动进程；明确创建成功后才显示绑定当前会话身份及工作目录的交互 Shell

#### Scenario: 执行节点不可用
- **WHEN** 目标节点离线、没有权限或不支持交互终端
- **THEN** 创建失败并给出具体原因，不回退本地节点、不启动普通命令进程冒充完整交互终端

### Requirement: 交互输入与执行授权清晰

系统 SHALL 支持交互输入、窗口尺寸同步、控制键和明确的粘贴行为，命令只来自用户对该终端的操作。来自聊天、文件、工具输出或恢复缓存的命令文本 MUST NOT 自动执行；多行粘贴 SHALL 在执行前提供可取消的检查。终端沿用实际进程权限，MUST NOT 自动提权或宣称等同于模型原生沙箱。

#### Scenario: 从对话复制多行命令
- **WHEN** 用户向终端粘贴含换行的脚本
- **THEN** 系统显示待发送内容及目标终端并允许取消，确认前不向 Shell 注入会执行的换行

#### Scenario: 调整区域和发送中断键
- **WHEN** 用户调整终端区域大小或发送交互中断键
- **THEN** 实际交互进程收到对应尺寸/控制信号；发送中断键不等于终端进程树已退出，状态按真实结果更新

### Requirement: 连接恢复复用进程且输出有界

系统 SHALL 为终端维护可核对的进程实例和输出位置，支持同一身份下的窗口交接及短暂断线恢复。输出缓存 SHALL 有界并具备背压；缺失历史明确显示截断。恢复 MUST NOT 重放已发送输入、重复启动 Shell 或把旧实例的输出注入新终端。

#### Scenario: 断线期间命令仍在执行
- **WHEN** 连接短暂中断后恢复且原终端仍存活
- **THEN** 视图重连原终端，补充保留范围内的输出且不重复输入；状态未确认时禁用发送并提示，而非新建替代进程

#### Scenario: 输出超过缓存上限
- **WHEN** 长任务输出超过保留范围或用户请求的恢复位置已不可用
- **THEN** 系统清楚标注缺失历史并展示可用尾部，内存和传输保持有界，不伪装为完整执行日志

#### Scenario: 执行端重启
- **WHEN** 后端重启后原终端已不可恢复
- **THEN** 原终端标为中断或最后状态未知，不按旧 PID 接管其他进程，也不自动重跑此前命令

### Requirement: 显式停止以所属进程退出为准

系统 SHALL 分别提供隐藏视图、关闭已结束标签和停止运行终端的语义。停止请求 SHALL 显示进行态，只有确认所属终端及受管理子进程已退出才报告完成；无法确认时保留活动保护和核对入口。命令自然结束与 Shell 仍存活 SHALL 可区分。

#### Scenario: 合并窗口或隐藏终端
- **WHEN** 用户合并独立窗口、切换 Chat 或隐藏终端区域
- **THEN** 原进程继续执行，同一会话可重新连接；隐藏视图不产生进程停止回执

#### Scenario: 停止请求超时
- **WHEN** 用户停止终端但所属进程树尚未确认退出
- **THEN** 显示停止未确认，不能仅因请求超时、视图卸载或任务取消就释放 LOOP 活动保护

### Requirement: 终端隔离与输出处理保持安全边界

系统 SHALL 在创建、输入、调整、订阅和停止时核验终端所属用户、节点、会话和客户端权限。终端输出 MUST 作为终端数据而非应用指令或 HTML 处理，不自动执行输出中的剪贴板、文件、链接或应用操作；输入和环境变量不得额外写入应用诊断日志或持久化命令重放记录。

#### Scenario: 跨用户使用终端标识
- **WHEN** 另一用户或错误节点提交已存在的终端标识
- **THEN** 系统拒绝操作且不泄露输出，持有标识本身不构成权限

#### Scenario: 输出包含控制序列或伪指令
- **WHEN** 程序输出请求写剪贴板、打开链接或执行应用动作的文本/控制序列
- **THEN** 系统不自动进行相应动作；普通显示控制序列受终端解析边界限制，不作为聊天指令或网页脚本执行

### Requirement: 终端纳入 LOOP 人工活动保护

系统 SHALL 仅允许符合当前控制权规则的 LOOP 会话创建或输入终端。仍可执行命令的存活终端 SHALL 被视为潜在写活动，即使画面空闲；交还 LOOP 前须显式停止并确认退出。终端命令成功 MUST NOT 证明模型环境已通过检查、消费旧队列或开启 Auto。

#### Scenario: 人工会话准备交还但 Shell 空闲
- **WHEN** LOOP 人工控制期间打开的 Shell 没有前台命令，但进程仍存活
- **THEN** 交还入口说明终端仍占用，提供定位和停止路径；停止并确认退出前不能提交交还

#### Scenario: 终端中验证成功后交还
- **WHEN** 用户手动测试成功，停止终端后合法交还 LOOP
- **THEN** 保留既有原生环境检查结论，Auto 仍按原规则关闭，不自动发起下一轮或执行排队消息
