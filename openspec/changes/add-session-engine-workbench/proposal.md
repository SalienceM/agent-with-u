# Proposal

## Why

当前会话只能在主窗口标签或分屏中使用，文件预览和编辑依附于弹窗，难以同时阅读代码、修改文件并与 Agent 协作。用户希望保留现有 Chat 体验，同时获得可分离、可合并的会话工作台，以及适合 Java、Python、Vue、React 工程开发的 Engine 模式。

## What Changes

- 为每个会话增加独立于普通/LOOP 类型的 Chat / Engine 展示模式；旧会话默认 Chat，原布局与交互保持不变。
- Engine 默认左侧目录、中间文件、右侧对话/LOOP 面板，底部可展开终端；默认切换三栏，不强制系统全屏。布局可调整并恢复。模式从 Session 右键菜单选择；Engine 将一个窗口作为当前 Session 的工程工作区，收起全局会话侧栏、隐藏工作总览/Session 标签条，回到 Chat 才恢复多会话导航。
- 会话支持 Detach / Attach：桌面支持应用内菜单及 Chat 标签拖出/合并，Web 提供独立窗口及显式合并入口；不增加原生顶部“会话”菜单栏。移动的是同一个会话工作台，不复制会话、不改变 Backend 或执行节点。
- 将预览与编辑提升为常驻文件工作区：可写本机代码、配置和纯文本直接编辑；远端始终只读，下载后优先打开独立本机副本，保存不自动上传。Markdown/HTML 默认预览，可切源码或并排；图片/PDF/Office 等沿用专用预览并如实标识编辑能力。
- 建立完整文档、独立草稿及撤销历史、项目导航/搜索、Git 差异和版本校验保存；堵住截断预览覆盖原文件与外部改动被旧缓冲区覆盖的路径。该安全底座也供原 Chat 编辑入口复用，但不改变 Chat 布局。
- 经用户确认，本机离线副本也保留编辑能力并纳入安全底座；分别适配 Tauri 本机目录、浏览器目录句柄和托管离线空间，不把本机保存当作远端保存。
- 按本轮追加要求，本机副本混合换行文本可编辑，保存保留编码/BOM和原行换行风格；远端编辑器限制同样约束格式化/重命名，下载草稿不发给远端 LSP。执行端语义编辑仍用于本机执行端工程，不将副本基础编辑标称为项目语义能力。
- 接入执行节点上的语言服务，面向 Java、Python、Vue 单文件组件、React JSX/TSX 提供工程补全、定义/引用跳转、诊断、格式化及可预览的重命名。依赖和项目导入权限不足时明确降级，不自动安装。
- 首版提供真实交互终端，绑定会话所属执行节点、工作目录和用户；由用户显式创建并输入命令，支持停止、尺寸调整及有界断线恢复。
- 草稿、流式进度、文件状态和终端引用经过确认后才能移交窗口；授权不随视图复制。新写入口参与 LOOP 手动控制和活动保护，终端成功不被当作自动 LOOP 环境通过。

本次不承诺完整 VS Code 扩展兼容、断点调试、多用户实时协同编辑或 Office 文档编辑，也不自动运行项目、发布制品或修改全局开发环境。分阶段实施不等于将四类语言服务或终端从本变更验收范围移除。

## Capabilities

### New Capabilities

- `session-workbench-modes`: 会话级 Chat/Engine 模式、三栏布局、文件默认打开方式和窄屏适配。
- `session-window-handoff`: 会话工作台分离/合并、可靠状态交接、恢复及窗口身份隔离。
- `workspace-document-editing`: 完整文档模型、安全保存、草稿恢复、文件标签、项目导航及变更比较。
- `workspace-language-services`: 实际执行节点的语言服务与四类工程语义能力、诊断及有界生命周期。
- `session-terminal`: 会话所属节点上的交互终端、明确的运行授权与进程/连接生命周期。

### Modified Capabilities

- `loop-control-handoff`: 增加工程工作台写活动和终端的转交保护；只读视图及无工作区写权限的语言服务不凭存在就永久阻塞转交。保留原有空人工轮、队列和 Auto 规则。

`loop-execution-environment` 的现有契约保持不变：人工终端与语言服务可用不证明模型原生调用环境可用。

## Impact

- 前端：`App.tsx`、`ChatPane`、`Sidebar`、`FileTreePanel`、`CodeEditor`、工作台状态与独立窗口工具；复用现有预览渲染器，新增共享文档、窗口交接、语言服务和终端视图层。
- 后端：Session 元数据及存储兼容、`BridgeWS` 的授权/路由和 LOOP 活动判断、新的版本化文档读写、语言服务及终端管理器；普通文件同步/传输调用的既有语义不暗改。
- 桌面与依赖：Tauri 会话窗口入口和最小权限配置；终端渲染与 PTY 支持；语言服务提供器及其版本/运行时矩阵。服务仅运行在实际执行节点，不在 Relay 转发服务器或错误的控制端启动。
- 验证：扩展工作台、文件预览、会话恢复和 LOOP 现有测试；增加双窗口交接、数据丢失防护、PTY/LSP 协议与真实隔离工程夹具。保留工作区已有修复和版本改动，不纳入本提案的实现成果。
