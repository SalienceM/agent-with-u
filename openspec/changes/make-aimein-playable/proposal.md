# Proposal

## Why

AIMEIN 已经保持沙盘常驻，但模块主要用于打开面板，缺少让 MC 老手和极客愿意主动再试一次的操作循环。用户确认以“好不好玩”为标准，需要把组合、排故、评委调试和真实成长变成可操作的世界。

## What Changes

- 增加观察、装配、探针、评委工具栏和键盘等价操作；目标方块可拿起、选取并显示依赖。
- 装配台组合真实子目标，包含所需依赖；显式提交有来源的建设意图，通过现有意见流进入下一次规划，当前冻结 Sprint 不被客户端改写。
- 场景开工入口复用真实执行入口和门槛；操作回执、运行搬运、保存产出与验收分别表达。
- 故障探针查看实际步骤输出、错误、评审缺口和来源；从评委席进入对应校准。
- 将实际历史尝试做成可点击的世界足迹，回看当时成果；目标瓶仍只由共同核实证据填充。

## Capabilities

### New Capabilities

- `aimein-playable-workshop`: 沙盘内模块装配、执行、排故、评委调试和真实历史足迹的操作循环。

### Modified Capabilities

无。已有常驻场景和执行语义保持，新增操作层。

## Impact

前端 AimeinWorkbench、AimeinWorld/Scene/Static、ReviewLibrary、LoopPanel 及隔离测试；复用 loopAddAddon 与现有执行、评委协议，无新依赖、无自动启动、无生产模型调用、无安装包变更。更新独立模式文档与实际浏览器录屏。
