# Spec Delta

## Purpose

在用户明确启用的 Session 中，于回答完成后提供可直接采纳的简短后续表达建议，减少重复组织文字。建议作为可忽略的输入辅助，与用户草稿、模型执行、工具授权及真正发送保持独立。

## ADDED Requirements

### Requirement: 独立开关与完成后生成

系统 SHALL 提供与 Kit 代确认同排的 Session 级影子建议开关，默认关闭并持久化用户选择。仅启用且收到新的成功完成回答时 SHALL 至多启动一次有界辅助生成，不恢复主原生线程、不执行工具；失败、中断、重连重播及打开旧会话不得触发生成。

#### Scenario: 关闭时正常聊天
- **WHEN** 新 Session 或明确关闭建议的 Session 完成回答
- **THEN** 不产生建议模型调用，也不产生影子内容

#### Scenario: 重复完成事件
- **WHEN** 同一回答因重连收到多次完成事件
- **THEN** 至多生成一份建议，不重复消耗调用，不改变正文完成状态

### Requirement: 非侵入式接受与取消

系统 SHALL 在空白且适合输入的草稿中显示影子内容，Tab 接受为可编辑文字，Escape 隐藏；点击可用的等价控件满足触屏操作。接受不得发送、排队或赋予任何授权。用户正在输入、输入法组合、选择文本或操作引用菜单时 SHALL 保持原交互优先。

#### Scenario: 建议晚于用户输入到达
- **WHEN** 建议生成期间用户开始写入或加入附件
- **THEN** 新草稿和附件保持原样，旧建议不覆盖、不移动光标，也不在用户清空后重新突然出现

#### Scenario: 引用菜单占用 Tab
- **WHEN** 文件、角色或命令菜单展开且存在影子建议
- **THEN** Tab 只作用于当前菜单，不同时填入建议，不触发发送

### Requirement: 建议限定身份和材料

系统 SHALL 绑定建议到用户、执行节点、Session、来源回答和草稿修订，仅使用有界可见文本。系统 MUST 排除隐藏推理、临时令牌、历史授权及附件原始内容，且不得将建议本身作为下一轮用户输入或权限选择。切换身份、关闭功能或新一轮开始 SHALL 使过期建议失效。

#### Scenario: 生成失败或节点离线
- **WHEN** 建议调用失败、不支持纯文本辅助调用或超时
- **THEN** 普通输入与主回答不受影响，提供简洁的不可用状态，不切换其他 Backend 重试或把错误当作影子文本
