# Design

## Context

动机与范围见 [proposal.md](proposal.md)，行为契约分别见 [Excel 专项](specs/excel-preview-interaction/spec.md) 与 [公共文件预览](specs/file-preview-interaction/spec.md)。本次跨越预览宿主、共享标题栏和各格式内容，需要将尺寸与输入职责分开处理。

已读实现中的关键约束：

- `ExcelPreview.tsx` 使用 HTML table、原生 `overflow: auto` 和 sticky 冻结行列；已有点击选择、搜索、缩放和复制，没有表格平移手势。逐单元格 `onClick` 需要与新增拖动协调。
- Excel 工具栏与底栏包含不换行内容，搜索宽度使用窗口单位，不能正确反映 Engine 分栏的实际宽度。公式栏主要靠省略号和悬停显示长内容。
- `FilePreviewToolbar.tsx` 已把关闭按钮放在可横向滚动的操作组之外，但同一行还有固定占宽项，且现有按钮不具备 44px 触控命中区。仅移动关闭按钮的 DOM 顺序不足以解决挤压。
- `FileTreePanel.tsx` 的普通弹窗为 `82vw × 82vh`，内容外层可滚动；`StructuredFilePreview.tsx` 又承载 Excel 高度及截断提示。独立窗口使用 `100dvh`，仍有外层滚动容器。必须沿整条容器链约束尺寸，不能只修表格 CSS。
- 现有 Office 浏览器用例虽以 `.xlsx` 命名，其预览数据实际是 Word，不能作为网格手势或手机关闭验收。手机现场裁切尚未复现。

## Goals / Non-Goals

**Goals:**

- 将浏览位置限定为网格原生滚动状态；宿主负责可用空间和退出，Excel 负责表内交互与阅读工具。
- 鼠标、触摸和输入控件各走适合自己的事件路径，不引入第二套滚动坐标或大量指针移动重渲染。
- 使用组件实际宽度决定工具密度；断点、软键盘和宿主切换不重建工作簿阅读状态。
- 通过输入事件、滚动增量、命中测试及关闭结果证明交互可用，清楚区分模拟器验证与真机证据。

**Non-Goals:**

- 不改解析、RPC、工作簿数据模型、保存权限或 Session 状态；不增加前端库。
- 不复制 Drawio 的画布变换和全局 `touchAction: none`；不把表格改造成画布或编辑器。
- 不统一所有格式的外层滚动，也不借此改造全应用 Escape、弹窗和窗口生命周期。

## Decisions

### 1. 沿宿主到网格分配尺寸，关闭入口独立占位

`FileTreePanel` 保留 Chat 弹窗与 Engine 文档栏两条宿主路径；`FilePreviewWindow` 保留独立窗口退出路径。手机宽度下各格式文件预览弹窗默认填满可用视口，不把 Engine 强制切成弹窗，也不修改预览/源码/编辑的默认打开方式。

共享标题栏分为有界文件身份区、可收纳操作区和不可收缩的退出区。窄屏允许标题截断、次要操作进入显式入口；文件完整名称和来源可点击查看，不依赖 title。退出区预留至少 44 × 44 CSS px，不参与横向滚动，不用绝对定位覆盖工具来掩盖溢出。Engine 当前文件的退出入口沿用文档标签语义并核对其窄栏可达性。所有关闭动作仍调用原有关闭函数及草稿保护。

手机外框采用固定定位、动态视口高度和安全区内边距。复用已有可见视口处理；若只有 `dvh` 不能覆盖键盘缩小后的可见区域，在该弹窗范围内用 `visualViewport` 的尺寸/偏移订阅补充定位，并提供无此 API 时的 CSS 回退。监听在关闭时清理，不改全局 viewport meta、不禁用用户缩放。高度不足时收纳次要工具并限制展开层高度，优先保留标题退出与可操作网格。实现时须验证横竖屏、键盘与页面缩放，不把视口事件当作重挂载依据。

替代方案：仅把关闭按钮设为 fixed 无法修复父容器溢出与层级遮挡；所有宿主统一全屏会改变现有工作流，均不采用。

### 2. 保留原生滚动，明确每个区域的滚动所有权

宿主内容链使用 `minWidth: 0`、`minHeight: 0` 和受约束的 flex 布局。自带滚动的富预览使用有界剩余空间；普通文本/图片需要的滚动由相应内容包装层承担，不把所有格式统一成 overflow hidden 后导致内容不可达。提示条与内容分别分配高度。Excel 网格是表内容双向滚动区，工作表标签独立横滑，工具/长内容展开层只滚动自己的内容。

`StructuredFilePreview` 为截断提示明确保留空间，网格使用剩余高度，避免 `height: 100%` 再叠加提示超出外框。网格设置合适的 overscroll containment；同时依赖有界宿主避免底层滚动，不能仅依赖某个浏览器的边界手势特性。

保留 table 与 sticky 冻结窗格，不对网格整体做 transform。键盘及搜索定位从可能滚动所有祖先的 `scrollIntoView` 收敛为网格内的有界滚动调整，计算可见范围时避开冻结行列/标题；不扩大当前冻结、预览行列数或缩放范围。

替代方案：全外框统一滚动会把工具和退出一同带走；画布平移会重新引入冻结、命中与无障碍成本，均不采用。

### 3. 鼠标采用轻量手势状态，触摸继续原生滚动

鼠标主键在网格可浏览区域按下时记录 pointerId、起点、原滚动位置，进入待定状态。建议初始移动阈值为 6 CSS px，这是实现默认值而非用户指定参数；通过测试允许小幅抖动仍算点击。超过阈值才进入平移，使用起点与当前位置差更新原生 `scrollLeft` / `scrollTop`，并在需要时捕获指针，以便离开边界仍能正确结束。

手势状态和高频位置使用 ref，只有开始/结束的光标等视觉状态需要更新组件；不能每个 pointermove 重新渲染整表。实际平移时避免浏览器选中文字。释放后只抑制本次拖动产生的 click，下一次独立点击必须恢复。未跨阈值的点击沿原单元格选择路径；右键、输入控件、复制按钮、缩放选择器和工作表标签不进入平移。

pointerup、pointercancel、lostpointercapture、窗口失焦、工作表变化及卸载统一清理状态和监听。清理必须幂等，避免取消后残留抑制标记吞掉下一次点击。

触摸不进入鼠标模拟平移：允许浏览器原生双向滚动与页面缩放，不在 touchmove 中反复写滚动位置或无条件 preventDefault。只做必要的轻触/滑动区分；原生取消事件也清理选择抑制状态。触摸与鼠标输入类型切换不能继承旧手势。

替代方案：把所有 pointer 都转成手动平移会与惯性、缩放及软键盘争抢；任何移动都算拖动会破坏点击。两者都不采用。

### 4. 阅读工具按容器宽度收纳，保持状态与焦点

使用容器宽度观察或项目已有等效机制决定紧凑布局，而不是仅依据 window 宽度；建议约 640 CSS px 进入紧凑模式，具体断点由实际控件占宽验证。布局和样式遵守现有组件内样式约定，不新增全局 CSS 改造。

宽屏保留直接可见的工具；窄屏使用紧凑搜索/工具入口展开搜索、缩放和统计。文件、当前工作表与选中单元格仍可辨识。工作表标签获得可收缩但可滚动的区域，统计移入紧凑信息区，不用固定统计宽度挤空标签。

长内容/公式有明确展开入口，在有界面板内换行、滚动和复制。复用已有焦点/浮层基础设施；展开层有自己的关闭及焦点返回，不覆盖宿主退出入口。不添加全局 Escape 捕获来替代既有关闭行为。完整展示仅指已经收到的预览内容；截断提示与无缓存公式状态继续保留。

搜索词、选择、工作表及缩放保存在现有查看器状态中，不随折叠切换或容器变化重置。搜索控件内的方向键、文字选择与 Ctrl/Cmd+C 先遵循输入控件语义；网格导航/复制只在适当焦点域生效，不能靠冒泡抢占所有子控件。

替代方案：缩小整界面会降低触控可用性；直接隐藏工具会损失能力；悬停 tooltip 无法覆盖手机，因此均不采用。

### 5. 各格式适配而非统一抢占手势

| 格式 | 源码证据 | 处理决定 |
| --- | --- | --- |
| Word 版式 | 保留纸张宽高，内部 overflow auto，无缩放/手形入口 | 保留渲染器；新增页面缩放包装与正确滚动占位，适配宽度随容器变动，手动倍率不重置。默认选择文字，显式手形复用鼠标平移；原生触摸滚动。不能对选字模式无条件 preventDefault |
| Word 兼容 / PPT | 纸张 48px 水平留白、图片上限 280px、PPT 网格下限 330px | 兼容视图按宽度收紧留白，图片 max-width 不超容器，宽表局部滚动；PPT 最小轨道不能超过 100% 可用宽度。不声称原始分页/动画保真 |
| PDF | 固定 1.2 倍、居中 flex 画布，工具单行 | 首次适配容器宽度，缩放仍有上限并保持单页渲染。可滚动占位宽度等于实际画布，宽页以左边可达为前提居中；适配/手动模式分开，复用原生滚动平移 |
| Markdown | 260px 目录，media query 和 matchMedia 依赖窗口 | 改为容器判定，窄栏目录成为内部展开层；目标定位只动文档 scroller；保留既有渲染、复制、源码和并排 |
| HTML | 不换行工具组、iframe min-height 240px、多条提示 | 工具可换行/收纳，提示有界，iframe 获得剩余空间而非强占 240px；不更改 sandbox、信任开关、资源路由或捕获 iframe 内手势 |
| 图片 / Drawio / 源码 | 图片使用窗口 vh；Drawio 已有两模式手势；CodeMirror 自带滚动 | 图片用宿主尺寸等比适配；Drawio 只调整工具/外框并回归其原手势；编辑器保留选择、快捷键及历史，不附加通用拖动 |

共享部分仅限尺寸观察、可见视口、可选鼠标平移及有界工具展示。无需通用格式适配器平台或新依赖。Word 缩放必须同步实际滚动占位，不能只 transform 视觉内容而留下不可达区域；不因容器 resize 重新解析文档。PDF 不新增 text layer，避免把现有 canvas 当成可选文字。

### 6. 建立真实格式与宿主组合的输入验收

新增真实 `kind: 'excel'` 结构化夹具，覆盖宽高均溢出的表、长标题/来源、多工作表、冻结/合并/隐藏行列、长公式/内容和截断状态。夹具保持既有解析上限；沿用 `tests/test_file_preview.py` 核对后端结构，不引入实际用户文件或生产 Session。

补真实可解析 DOCX、PDF，分别验证版式成功与兼容失败路径；PPT 使用实际结构化 payload。Markdown、HTML、图片、代码使用各自渲染器与真实交互，不再让所有 Office 文件都返回 Word 替身。上述宽度矩阵覆盖每种格式的外框退出，复杂手势按格式测试；HTML/Drawio 验证隔离未扩大。真机验证依然独立列项。

使用 `frontend/tests/engine` 隔离 React harness 与 Playwright 配置，测试输入而非只测试 DOM 存在。验收至少覆盖：

| 范围 | 操作和证据 |
| --- | --- |
| 桌面网格 | 实际 mouse down/move/up 改变双轴滚动；拖动不改选择，随后点击可选；离开网格释放、取消、失焦及切换表后无残留 |
| 触屏网格 | 浏览器触摸输入滑动后的真实滚动增量与轻触选择；不能用直接赋值 scrollTop 代替手势验收 |
| 手机 Chat 弹窗 | 320/360/390px、横屏、长标题与多标签；关闭矩形在可见视口内且至少 44px，中心/边缘命中检查并实际点击关闭 |
| Engine / 独立窗口 | 宽桌面中的窄文档栏、窗口收窄；无宿主横向溢出，退出作用域正确，原窗口/草稿守卫不绕过 |
| 阅读工具 | 紧凑展开、搜索定位、缩放、标签横滑、长内容复制和焦点返回；状态不重置，关闭不被遮挡 |
| 异常与共享格式 | 加载/空/失败/截断可退出；Markdown/文本/PDF/Word 与未保存确认不回归；浏览动作无写入请求 |

保存关键布局截图供检查，但截图不能代替输入和命中断言。软件键盘、安全区、惯性和移动端浏览器栏存在平台差异：浏览器仿真结果与可获得真机结果分开记录；未获得真机证据的项目保留待验证，不将模拟 resize 或静态代码检查标成真机通过。触摸自动化若受运行环境限制，明确留下未验证项，不以普通脚本 scroll 兜底冒充通过。

## Risks / Trade-offs

- [拖动与 click 的事件顺序在浏览器间不同] → 使用单次手势关联的抑制与统一清理，覆盖下一次点击、取消、捕获丢失和触摸转鼠标；不使用长期全局阻止点击。
- [关闭按钮单独占位仍可能被祖先宽度或浮层裁切] → 从宿主到表格核对约束链，按真实宽度、命中目标和关闭结果验收，不止检查 display 属性。
- [移动端动态视口及安全区模拟有限] → 采用 CSS 加有界可见视口订阅，保留原生缩放；模拟测试与真机验证分列，不作无证据兼容承诺。
- [共享标题栏影响文本草稿或独立窗口] → 保留原回调/窗口守卫，增加不同格式与有未保存修改的关闭回归；Excel 特有滚动调整按类型限定。
- [表内拖动不再适合直接划选单元格文字] → 本次明确是阅读平移而非范围选择，保留轻点、完整内容面板和复制入口；不改变输入/展开内容的文字选择。
- [冻结行列遮挡搜索或键盘目标] → 保留原生 sticky 坐标，定位只修改网格滚动，夹具验证冻结交界和可见范围。
- [已有其他未提交改动导致交叉影响] → 实施前核对目标文件差异，只修改本变更必要部分，不重写其他变更或把其验收纳入本变更完成度。

## Migration Plan

无需数据、配置或协议迁移。实施按宿主尺寸/退出、滚动边界、鼠标手势、紧凑工具与回归验收分步完成，共用同一只读查看器，不保留第二套 Excel 引擎。

完成自动化及可获得的设备验收后记录证据与未验证范围，再进入后续发布流程。本方案不授权打包、发布或更新正在使用的客户端。回退只撤销本变更的交互和布局改动，保留用户工作簿、预览数据与其他变更；不清理 Session 或重置仓库。
