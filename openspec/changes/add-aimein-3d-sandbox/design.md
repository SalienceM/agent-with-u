# Design

## Context

现有 AimeinWorld 是静态等角 SVG；AimeinWorkbench 管理阶段选择、观察区和意见草稿。goalObservation 已将完整三方目标依据归约为已核实数。计划与详细评审按需加载，紧凑推送并不包含完整目标。项目使用 React 18、Vite、内联样式。

## Goals / Non-Goals

**Goals:** 复用上述状态和操作，将目标模块、目标瓶和评委交互变成连续、可终止的 3D 体验；提供真实浏览器录屏。

**Non-Goals:** 不改变后端执行协议、评分和权限；不生成真实产品建筑模型；不训练模型，不将视觉操作视为任务执行。不在第一版引入物理引擎、全屏后处理或 D3 全量依赖。

## Decisions

- 使用 React 18 兼容的 R3F 8 与 Three.js，懒加载 Canvas 模块；原 SVG 改为兼容视图。相比直接管理 Three.js 生命周期，R3F 更适合现有组件及事件；D3 数据布局本轮不必引入。
- 状态投影使用真实目标 ID、依赖和阶段状态。拆分布局、聚合布局均确定性计算，最多 40 个目标。显式视觉回放只更改本地镜头和布局状态，不能请求任何执行 RPC。阶段从规划进入执行时改变布局；相同状态推送不重复播放。
- 液面使用 goalObservation，数字始终显示最终观察值；液面过渡仅为状态插值。历史切换标出观察版本，不播放“新增完成”庆祝。未知为空且显示待核实。
- 低多边形浮岛、方块工坊、透明瓶壳、独立评委座位。固定斜俯视初始角度，限制轨道控制范围；点击对象缓动聚焦，回到全景可恢复。HTML 对象按钮作为触摸和键盘等价入口，详情仍使用原观察区。
- 场景扩大为主要区域；观察区按选择展开，窄屏滚动到观察内容，保留顶部运行/停止等现有控制。详情与意见草稿不因视觉模式切换丢失。
- 按需帧循环，动画活动时才 invalidate；后台和离屏暂停并收敛到当前状态。限制 DPR，复用几何体/材质；低画质关闭抗锯齿或降低像素密度。尊重 prefers-reduced-motion，提供用户静态视图切换。加载失败与 contextlost 进入原 SVG，避免反复重建上下文。
- 验收采用现有隔离 QA 服务与合成评审数据，浏览器记录实际 WebGL 动画为视频并截帧。覆盖键盘、窄屏、降级、减少动效、历史/重复推送与无执行副作用。性能记录说明测试设备和软件渲染限制，不声称生产 Tauri 已验收。

## Risks / Trade-offs

- [GPU/驱动差异] → 不强求 WebGPU，保留静态降级；生产设备帧率需单独观察。
- [动画误导完成度] → 复用共同核实算法并标注观察版本，回放不改数据。
- [三维标签拥挤] → 场景内主要对象配合 HTML 选择入口，完整文档在观察区阅读。
- [包体增加] → 3D 模块动态分包，普通聊天不加载；不额外引入物理与后处理库。

## Migration Plan

无需数据迁移。升级前端即可；静态视图随时可切换，移除懒加载入口可恢复旧 SVG。独立文档更新到下一版本，记录依赖、回放语义和验收范围。
