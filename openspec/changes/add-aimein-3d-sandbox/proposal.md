# Proposal

## Why

AIMEIN 已有可审计的目标、成果、意见和评委档案，但静态 SVG 不能直观表达拆分、聚合和核实的连续过程。用户希望在实际工作台中操作有空间感的建设沙盘，并查看实际动效。

## What Changes

- 将建设场景升级为按需加载的轻量 3D 沙盘，保留静态兼容视图和可访问的对象入口。
- 用真实子目标与阶段状态驱动拆分、聚合；提供明确标为视觉回放的操作，不执行任务。
- 目标瓶平滑呈现所查看版本的共同核实覆盖，未知不变成完成，历史切换不冒充新增成果。
- 三位评委可直接点击观察；镜头聚焦与选中反馈连接原有证据、意见和档案入口。
- 控制静止、后台、离屏和减少动态效果时的渲染成本，进行桌面、窄屏和降级验收并录制运行效果。

## Capabilities

### New Capabilities

- `aimein-3d-sandbox`: 3D 建设沙盘、状态动效、对象交互与性能降级。

### Modified Capabilities

无。依赖尚未归档的 `evolve-aimein-world-and-reviewers`，继续遵守其目标覆盖、意见和评委档案语义。

## Impact

主要修改前端 AimeinWorld 和工作台布局，新增 3D 场景与状态投影模块、React 18 兼容的 Three.js/R3F 依赖、隔离浏览器验收与录屏。复用原 BridgeWS 和后端状态，无新模型调用或数据协议写入；同步独立设计文档。
