# Spec Delta

## Purpose

为 AIMEIN 提供可发现的创建入口和阶段工作台，让用户直接理解功能与基础设施范围、成熟度要求、三模型评审和修补原因，并在桌面与窄屏可靠操作、查看历史和恢复任务。

## ADDED Requirements

### Requirement: 模式创建与评审配置清楚可用
系统 SHALL 提供 AIMEIN 创建入口、三个评审模型的配置和具体缺项提示；创建本身不启动模型，配置保存失败必须可见。旧 LOOP 和普通会话保持兼容。

#### Scenario: 新建 AIMEIN
- **WHEN** 用户选择 AIMEIN 创建会话
- **THEN** 打开阶段工作台，展示目标准备及模型配置入口；不出现自动执行或配置成功的虚假反馈

### Requirement: 阶段与评审可交互查看
工作台 SHALL 分开显示当前 Sprint 与尝试、FlowBuild/Infra、目标成熟度、三位评审状态、必修问题及历史详情；选择旧记录不得被新推送抢回。成熟度 MUST 标为阶段评审判断。

#### Scenario: 查看分歧及历史
- **WHEN** 用户展开评审问题或选择旧尝试
- **THEN** 展示对应版本的条件和证据，详情按需加载，流式结果归属正确评审，查看不发起执行

### Requirement: 窄屏与操作反馈可靠
界面 SHALL 支持窄屏换行、可键盘使用的选择与展开、提交/接收/失败/未知反馈及停止恢复；详情具备焦点返回，用户/节点/会话结果隔离。重复点击不得重复写入。

#### Scenario: 窄屏操作
- **WHEN** 用户在 390 像素视口查看阶段并打开设置
- **THEN** 主要内容不横向溢出，模型配置与执行反馈可见，可通过 Escape 返回原入口
