# Spec Delta

## MODIFIED Requirements

### Requirement: 来源快照展示与兼容

系统 SHALL 在 LOOP 以紧凑来源摘要展示已绑定 change 及当前/过期/冲突/不可用状态，并在按需任务来源详情中展示来源身份、最近核对时间、正式任务数量及与评审的差异。未绑定时 SHALL 提供可发现的任务设置入口，不常驻完整来源管理卡；阻碍执行的来源异常 SHALL 提升至统一需要处理区。完整快照 SHALL 按需读取，不进入普通聊天历史或高频广播；跨节点、跨 Session 和旧修订响应 MUST NOT 相互覆盖。旧 LOOP SHALL 不被静默自动绑定。

#### Scenario: 旧 LOOP 加载
- **WHEN** 旧 LOOP 没有来源绑定字段
- **THEN** 系统在任务设置中显示未绑定并维持原通用行为，不从历史自由文本自动猜测权威 change；用户可空闲时显式绑定，打开工作台不触发自动发现

#### Scenario: 切换会话后晚到快照
- **WHEN** 用户在来源查询未返回时切换节点或 Session
- **THEN** 晚到结果仅属于原请求身份，不修改当前绑定或展示为当前任务清单，重连与重复推送不形成轮询

#### Scenario: 正常绑定的日常使用
- **WHEN** 来源已核对且没有范围冲突
- **THEN** 总览只保留来源摘要，点击后可查看完整身份和核对记录；改绑、解除绑定及处置依据不常驻主操作区

#### Scenario: 来源异常需要处理
- **WHEN** 来源不可核对或范围冲突阻止后续工作
- **THEN** 需要处理区直接显示原因并定位至相应差异/核对操作，仍保留显式确认、只读查询和空闲修改门槛，不因界面简化自动确认范围或启动执行
