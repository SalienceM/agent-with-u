# Design

## Context

参见 proposal.md。现有 targetPosition 按 9 个目标增高，assemblyPosition 按 20 个增高；所有依赖同时绘制，所有标签穿透深度。目标空间还与工坊、树木重叠。已有真实运行投影、目标瓶信用、自动装配与三方评审保持原语义。

## Goals / Non-Goals

**Goals:** 明确的平面任务地块、同一布局入口、聚焦依赖观察、少量常驻标识、清楚可定位的多页任务。

**Non-Goals:** 不更改执行调度、验收、后台权限；不导入参考游戏素材；不增加渲染库。

## Decisions

1. 参考 [Dorfromantik 官方截图](https://www.toukana.com/dorfromantik/presskit) 的独立地块和地形分区，以及 [Mini Motorways](https://dinopoloclub.com/games/mini-motorways/) 的简洁地图与有限色彩。这是本项目的视觉取舍，不复制游戏素材。
2. 地块保持单层、低高度、周围留白。拆分与聚合只改变水平间距和阶段强调；装配以同位置标记表示系统范围或用户草稿，不再另建重叠坐标。最多 12 个目标一页；页数、总数和定位选择始终可读。拒绝无限缩小目标和无限扩张地面，以保障现有镜头、工作流路线和窄屏。
3. 全量目标保持原始顺序与稳定身份。翻页不改选择或业务范围，外部新选择可定位相应页，历史身份变化复位；重复流式推送不抢页。静态模式也提供等价目标入口。
4. 默认移除全量依赖线；仅选择/悬停任务展示直接前置与后继，有方向标记；跨页关联及缺失 ID 在任务说明中提供定位或未知提示，完整传递依赖仍由观察区呈现。长标题在 HTML 说明中展开，场内仅短编号，避免始终置顶的标牌重叠。
5. 地形降低棋盘对比；任务使用薄地块、紧凑模型和状态刻度；工坊/基础设施/评委保留独特轮廓与少量颜色。缩小标牌、历史足迹仅悬停/选中标记，清理任务区边缘树木。动态仍由真实运行事件驱动，闲置/历史/减少动态不制造活动。

## Risks / Trade-offs

- 分页减少全图一屏直观性 → 常驻范围计数、全目标定位与关联跳转，不隐式删除任务。
- 低矮模块在远景更小 → 有限每页数量、独立命中面、悬停提示与键盘等价选择。
- 相机旋转仍可能造成投影遮挡 → 减少高度、保留间距，默认镜头和窄屏实拍检查；不承诺任意视角绝无遮挡。
- 变更视觉投影 → 以坐标间距、全量可达性、无额外执行调用、实时运动/历史保留测试验证。
