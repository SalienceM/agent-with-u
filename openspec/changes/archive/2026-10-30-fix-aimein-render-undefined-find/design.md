# Design

## Context

本条最初仅记录待办，现已获得 apply 授权。用户截图来自 Tauri 页面，错误为 `Cannot read properties of undefined (reading 'find')`，堆栈指向 `tauri.localhost/assets/index-…js` 压缩产物，界面已落入全局 `ErrorBoundary`，提供“重新加载／重试渲染”。截图本身未证明故障版本、具体组件、触发动作或哪个集合缺失；不将模糊的压缩符号当源码定位。已复现的空摘要读取缺陷及原截图证据缺口见 `verification.md`。

只读源码检查得到后续排查入口，而非根因结论：

- `AimeinRuntimePanel.tsx` 的归档输出回退访问 `current?.orchestration.find(...)`。
- `aimeinRuntime.ts` 的阶段和通道投影也访问 `record?.orchestration.find(...)`，以及 `.forEach(...)`。
- `AimeinWorkbench.tsx` 的评审选择访问 `summary?.reviews.find(...)`；评委库也有集合选择入口。
- 顶层可选链仅保护对象，不保证其集合字段一定存在；要核对共享控制器的紧凑／详情协议与真实传入数据。
- 既有 `fix-aimein-planning-render` 已处理空计划；现有浏览器夹具常补入 `orchestration: []`，不能据此证明真实紧凑记录的缺失集合路径已覆盖。

## Goals / Non-Goals

**Goals:**

- 后续将故障产物与真实触发数据映射到可复现的读取路径，明确合法省略、旧数据与坏数据的差别。
- 优先在类型／投影或数据接受边界统一缺失语义，组件保留有界防御，覆盖恢复和迟到数据。
- 按用户后续确认，修复 360px 窄屏下静态评委点击重叠、停止原因不可见及设置挤压画布。

**Non-Goals:**

- 不访问生产 Session 日志或数据，不改后台执行和评审规则。
- 不通过清空历史、默认全部通过、自动刷新或循环重试消除表面错误。
- 不改文件面板，不自动打包发布，不扩成全应用状态重构。

## Decisions

1. **证据先于补丁。** 后续先核对故障版本与最小触发序列，用隔离夹具复现压缩堆栈对应路径；不能仅给某个候选 `.find` 加可选链就宣布解决。单点盲改虽快，却可能遗漏后续 `.some`／`.map` 以及状态误报。
2. **展示安全与状态真实性并重。** 对协议允许缺少的详情保留未加载标记，在只读投影中使用安全集合；对不合法结构显示数据问题并保留已知内容。不能统一转成“空数组＝没有工作”。具体归一化位置以复现和协议核对结果确定。
3. **沿用身份隔离和只读恢复。** 使用现有控制器的详情合并／过期回复规则；恢复显示不新增执行或写重试。需要手动读取时复用现有明确入口。
4. **对照既有空计划修复。** 复用 `aimein-workbench-lifecycle` 路径，以新要求补充集合缺失生命周期，不重复改写旧变更已完成的空计划要求。
5. **窄屏不能只缩小图形而留下重叠点击区。** 静态对象与评委使用不重叠的可点击布局，选择仍关联原 reviewId；不以强制点击、隐藏评委或降低测试要求绕过问题。
6. **停止反馈属于主要状态。** 紧凑运行视图保留停止/结束原因，不只显示“已结束”；查看历史不挪用当前轮的停止原因，不新增请求。
7. **设置与场景保留各自可用空间。** 窄屏设置不能把场景压到不可观察；沿用独立滚动、相机与草稿状态，避免卸载重建画布。验证 360×640 视口、设置与返回流程以及可点击中心点。

## Risks / Trade-offs

- [截图不能定位源码] → 保留原错误文本与用户描述，后续核对准确构建与触发动作；不能在新编译产物中按旧偏移猜函数。
- [完整夹具掩盖字段缺失] → 用真实紧凑数据形状建立最小夹具，分别验证字段省略、空数组、错误类型与完整详情。
- [防崩溃把未知变为空或成功] → 针对状态文案、验收结果和操作入口添加断言，不仅检查“没有异常”。
- [测试影响生产数据] → 只使用合成执行端、临时测试用户和隔离浏览器；需要真实日志时先限定范围并脱敏。

## Migration Plan

不做持久数据迁移。按复现→修复→单元与浏览器回归→构建顺序推进；若发现需要协议迁移，先修订方案。发布、安装和重启另行授权，不包含在本变更中。

## Open Questions

- 故障安装包的确切版本、触发动作与复现频率尚未记录。
- 进入运行现场、历史记录、观察或评委页面中的哪一步触发，需要后续与堆栈对应。
- 当前源码已证实空摘要缺 reviews 的渲染路径，原安装包是否同因仍需核对；不能以当前夹具替代原故障版本证明。
