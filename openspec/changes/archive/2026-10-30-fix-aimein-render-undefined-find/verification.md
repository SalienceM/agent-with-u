# AIMEIN 稀疏记录渲染：实现与验证记录

日期：2026-10-30。工作区基线 HEAD：`6e0ca42`，工作区含其他未提交改动。本记录只描述本变更的隔离验证，不代表用户安装包或生产 Session 验收。

## 已证实的触发链

1. `src/backend/aimein.py::run_summary({})` 返回 `{}`。本次直接调用该纯投影函数验证，非推测。
2. `BridgeWS._loop_payload` 对记录写入 `aimeinSummary`，包括尚无 `aimeinRun` 的准备/历史记录；`loopGetRecord` 同样生成摘要。
3. `frontend/src/components/AimeinWorkbench.tsx` 原评审选择表达式为 `summary?.reviews.find(...)`。JavaScript 的空对象为真，可选链保护 summary，不保护缺失的 reviews。该表达式每次渲染执行，不需要先点评委。
4. 新浏览器用例 `empty backend AIMEIN summary survives the pre-attempt push` 注入 `{ orchestration: [], aimeinRun: {}, aimeinSummary: {} }`。修改实现前失败并进入全局 ErrorBoundary；trace 明确记录 `Cannot read properties of undefined (reading 'find')`，首帧为 Vite 转换后 `AimeinWorkbench.tsx:110:34`。源码位置为该文件评审选择表达式，不用构建偏移推断。
5. 修改后，同一浏览器用例通过。`aimeinRuntime` 与运行面板的步骤标签、通道和保存输出回退还存在相邻缺失集合风险，已用缺字段/坏集合夹具覆盖。

截图的安装包版本、原触发动作和压缩 bundle 对应关系仍未取得，不能断言截图那一次必定由同一个路径引起。任务 1.1 保持未勾选，未将此缺口默认为验收通过。

## 协议对照

| 字段/状态 | 后端事实及展示语义 |
| --- | --- |
| `aimeinSummary: {}` | `run_summary({})` 的正常“尚无尝试”哨兵；只读视图转为无摘要，不造出评审记录。 |
| 非空 `aimeinSummary` | 当前序列化包含 reviews、criteria、issues；省略这些字段是部分/旧数据，显示未提供或未加载。 |
| `orchestration` | 当前 `LoopRecord.to_dict` 总是发数组；compact 保留步骤但清空正文。省略是兼容性防御，不声称当前后端会省略。 |
| `aimeinRun: {}`、`detailLoaded: false` | compact 刻意不发详情；等待原有按需 `loopGetRecord`，不启动执行。 |
| `[]` | 明确为空，区别于没有收到字段；空评审不能认定通过。 |
| `undefined`/省略 | 未知；有详情请求时显示尚未加载，否则显示未提供。 |
| `null`、字符串、对象代替数组或坏数组成员 | 格式异常，不按空集合或有效报告计数；完整原始响应保留在控制器，投影不落盘。 |
| 目标/报告嵌套集合 | 坏目标依赖、报告条件/证据不进入场景和验收计算；当前合法完整数据维持原验收逻辑。 |

本次未读取或修改生产 Session 历史。后端协议不变，无迁移。

## 实现边界

- `aimeinRecordData.ts` 提供共享只读投影与集合状态；接在共享工作台控制器的 AIMEIN 展示出口，普通 LOOP 不使用该投影。空摘要与坏摘要分开处理。
- 步骤/评审/目标数据不完整时展示有界原因，缺少正文不显示“零个已保存”，不完整评审不能显示验收通过。
- 详情合并仅使用与当前 compact 修订匹配的缓存；原身份/代际检查保留。过期回复不灌入当前进度，新修订按原按需流程读取。
- 明确空集合和明确异常值不被详情覆盖成正常；仅省略字段允许由同修订详情补齐。
- 不改执行、Auto、停止、授权或后端评审规则，不自动重试写入。没有新增依赖。

## 一并修复的窄屏问题

用户明确要求将隔离回归发现的以下问题纳入当前 spec；对应任务 2.3–2.5，不另建变更。

- **静态评委按钮重叠：** 原按钮按图形百分比定位，图形缩小后文字点击区相互遮挡。窄屏改为静态图下方独立网格导航；保留全部对象、原 aria-label 和 reviewId。浏览器逐一检查三个评委按钮中心命中目标，并点击核对各自报告，不使用强制点击。截图复核又发现运行视图的静态图被控件挤压，追加图形最小高度和窄屏静态区域预留；仅任务地图独立滚动，图形与工具栏不随装配操作卷走。精简窄屏非交互说明，全部对象和工具入口保留，并断言图形大于 100px、装配切换后仍完整可见。
- **停止原因被隐藏：** 原紧凑视图只在错误或离线时显示运行提示，正常停止原因随之消失。现在明确展示当前轮真实停止原因，并保留原执行错误；切换历史尝试不带入当前轮原因。新增历史切换用例同时断言没有执行、Auto 或写请求。
- **设置挤压画布：** 360×640 打开设置时，场景工具栏和目标地图仍占完整高度，画布实测低于 100px。外部设置打开时复用已有紧凑观察布局，不重建画布；回归检查高度大于 100px、中心点可交互、同一 canvas 实例、相机和草稿保持。
- **历史条遮挡菜单：** 上述流程随后暴露窄屏“世界足迹”绝对定位覆盖评委按钮。历史条现在参与三维场景菜单正常滚动，静态模式有独立的同名菜单入口，桌面位置不变。第二次完整回归发现首次调整漏掉了静态分支的历史入口，已补回，并沿用原静态装配／历史切换用例核对。

针对上述流程的桌面与窄屏 8 项定向回归全部通过，类型检查通过。

静态图与装配的补充定向回归 10 项通过后，完整回归达到 67 项通过、1 项预设跳过。截图复核继续补足运行视图的空间分配：窄屏静态运行时，次级工具与地图收在可点击的场景菜单内，观察／装配时保留直接工具栏；避免静态区域扩大后挤住运行标题和停止原因。补充运行标题及静态停止原因的视口断言，最终结果以下方最后一轮为准。

最后的布局／状态定向回归 14 项通过，包含静态与三维的停止原因、历史归属和静态装配切换。已人工查看隔离截图：360×640 下静态图、对象按钮、运行标题、保存步骤计数与输出均可读，不只依赖元素存在断言。
