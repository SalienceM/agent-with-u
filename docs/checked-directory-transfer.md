# 向已有执行端目录上传或镜像同步

在文件面板的 **更多文件工具 → 本机副本与同步 → 上传变化 / 镜像同步** 打开预览。也可以右键文件上传，或右键目录选择 **镜像此目录到执行端…**。

先选定本机副本目录，两端更新到支持此功能的 AWU。桌面客户端也需更新，以使用完整目录扫描。

- **上传变化**：默认模式。按实际 SHA-256 和字节数比对，只传新增、变化文件；相同文件不传正文、不改写目标时间，目标独有文件保留。
- **镜像同步**：以本机目录为准。除上传变化外，还删除执行端在该范围内、本机没有的普通文件；不依赖旧同步基线。确认前会列出每个待删除路径。

预览显示来源、目标、范围、新增/覆盖/跳过/删除数量和实际传输量。选择镜像后，点击 **确认同步并删除** 才执行。只打开预览或取消不会修改目标文件。

镜像始终保留 `.git`、同步忽略项及所选目录外的文件，不执行 Git 命令，也不会 push 到 Git 远端。比对面板中的扩展名、文件名筛选不作为镜像范围；传输使用两端相同的同步忽略规则。空源目录可以清理对应目标范围的普通文件，但不会删除目标根目录或递归清除未知内容。浏览器托管副本不存空目录，消失的子目录不能冒充真实空目录；可从它仍存在的父目录预览镜像。

完整检查会读取实际文件内容，不能仅靠大小或修改时间省略哈希。范围内无法读取的文件、链接/目录联接、文件与目录冲突会阻止执行。当前每次最多 20000 个文件、8 GiB；超限会明确报错，不会用部分清单删除文件。

提交前会再次检查源目录和冻结的目标内容。预览后任一端发生变化，需要重新预览。正文先完整暂存并校验，再逐文件提交，最后清理多余文件；上传失败不会继续删除。跨文件操作不是整体事务，部分提交失败时显示已上传、已删除数量并保留实际结果，不自动回滚或重试。

确认后的进展保留在传输中心。关闭预览不等于取消任务；传输中心允许在提交目标前取消。目标提交开始后只能核对结果。断线或响应丢失时只查询原操作，不自动重发；服务进程重启后原回执可能不可用，此时保持未知，需要核对目录实际状态。

此入口更新已有执行端工作目录。“发送项目到节点 / 回传项目成果”仍分别创建独立项目或待合并分支；新功能不会自动覆盖 A 的原项目或改变原来的项目合并流程。下载方向保持现有行为，不提供镜像删除本机文件。
