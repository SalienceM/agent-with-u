# Session 导航与私密显示

## 导航会记住什么

Session 栏中执行节点、收藏和私密分组的展开/收起状态保存在当前客户端。节点改名、暂时离线或列表暂时为空不会清掉这个选择；同名节点分别记录。

已打开的 Session 标签、顺序、当前页和分屏位置也会保存。刷新优先恢复当前窗口；关闭后重新打开主窗口，恢复本客户端最近一次明确导航操作的记录。独立 Session 窗口只保存自己的布局，不覆盖主窗口。后台消息和列表刷新不会打开从未打开或已经关闭的标签。

这些偏好按客户端、用户和服务端范围隔离，不跟随账号同步到另一台设备。读取失败或离线时保留导航记录；未确认的会话显示中性占位。导航存储失败会提示重启后可能无法恢复，当前窗口仍可操作。

## 使用私密 Session

1. 在 Session 上打开右键菜单，选择“设为私密”。它只改变该会话的分类，不影响父子会话。
2. 在 Session 栏搜索框旁开启“显示私密 Session”，查看与收藏同级的私密分组。开关支持键盘操作。
3. 在私密会话菜单选择“取消私密”，恢复原来的收藏或节点归类。

私密和收藏是两个独立标记。私密会话可以继续收藏，但不会同时出现在普通节点和收藏分组中。

**显示开关只对当前窗口有效，刷新、重启和切换身份后都关闭。** 隐藏覆盖侧栏搜索、收藏、标签、分屏、首页卡片与活动、会话引用候选，以及会话工作台和相关浮层。完成通知不显示私密会话标题。已有公开聊天文本中的引用不会被追溯改写。

关闭显示不会关闭标签、丢弃草稿或文件缓冲区，也不会停止后台任务、清队列或提交窗口交接。再次开启会恢复已有标签的原有顺序；不会自动打开所有私密会话或抢走当前公开会话的焦点。独立 Session 窗口先确认元数据，再提供显式显示入口。

## 保存和同步

私密标记先保存到本设备，再向原执行节点同步。菜单和会话条目会显示“待同步”“结果未知”“私密冲突”“仅本设备”或“同步受阻”。收藏状态独立保留。

- 离线选择在本设备重启后仍有效，重新连接只协调原节点的最新选择。
- 结果未知时只读核对，不自动重发写请求；冲突可选择远端值或明确保留本设备选择。
- 本设备保存失败时不提交远端写入；私密记录无法读取时，相关会话保持隐藏，可使用“重新读取”。
- 旧执行节点不支持同步时，成功保存的选择仅影响本设备。与收藏一致，退出或切换账号会清理该身份尚未同步的本设备选择；应先处理需要保留的待同步记录。

私密是界面显示控制，不是加密或新的访问权限。旧客户端可能忽略该标记；回退旧版也不保证继续隐藏。已获得授权的 API 和工作区文件访问不因显示开关改变。
