# 使用 Engine 工程工作台

Engine 在现有 Session 上增加文件工作区、工程语义服务和交互终端；不是新 Backend，
也不是完整 VS Code 兼容层。Chat 保持原对话体验。两种布局均可用于普通会话和 LOOP，
切换布局不会改变控制权、开启 Auto、发送消息或启动工程。

## 切换与文件导航

在会话列表或 Session 标签上右键，选择 **Engine · 工程工作区**：左侧目录、中间文件、右侧原对话或 LOOP 面板。
Chat 不再额外显示一行会话工具栏，模式和窗口功能都在上方 Session Tab 的右键菜单；选中标签后也可按 Shift+F10 打开、Escape 关闭并回焦。
Engine 的当前会话标题菜单支持点击、右键与键盘操作，可从这里返回 **Chat · 多会话**。
Engine 隐藏全局会话侧栏和“工作总览 / Session 标签”行，一个窗口只关注当前 Session；
其他会话导航会提示先返回 Chat。返回后恢复原多标签、分屏和草稿，不停止后台任务。
目录/对话可折叠，分隔条支持拖动和键盘调整；窄屏使用区域切换，返回宽屏恢复原栏宽。
不强制操作系统全屏。模式按会话保存，布局按用户、节点、会话和窗口隔离。
旧执行端只支持明确标注的本地模式记忆，不能据此使用不支持的编辑或窗口交接。

Engine 顶部只保留当前会话菜单、目录/对话/终端图标、语言服务与窗口操作，不再平铺 Chat/Engine 按钮。
图标支持悬停提示及键盘焦点；“窗口与布局”（···）提供重置布局和低频恢复操作。
目录与文档使用主题底色，壁纸不会直接透过代码；原 Chat 内容布局保持不变。

- Java、Python、JS/TS、JSX/TSX、Vue 等源码默认进入源码视图；本机可写文本直接编辑，远端只读。
- Markdown/HTML 默认常驻预览，可切源码或并排，共用同一份草稿。
- 图片、PDF、Office 使用专用预览。二进制、损坏编码、截断或超限内容不开放通用保存。
- 最多 32 个文件标签，每文件独立撤销、选择和滚动状态；不能以腾空间为由自动丢弃脏文件。

| 操作 | 入口 |
| --- | --- |
| 快速打开 / 项目搜索 | Ctrl/⌘+P / Ctrl/⌘+Shift+F |
| 文件内查找、替换、跳行 | 文件工具栏“编辑导航”（···）与 CodeMirror 快捷键 |
| 保存 / 保存当前来源全部 | Ctrl/⌘+S / Ctrl/⌘+Shift+S |
| 导出/放弃草稿、比较合并、保存此来源全部 | 文件标题栏“文件与草稿操作”（···） |
| 定义 / 引用 | F12 / Shift+F12；需语义服务就绪 |
| 重命名 / 格式化 | F2 / Shift+Alt+F；也可点击文件上方按钮 |

聊天文件链接、搜索结果、定义和问题列表都定位同一文件缓冲区。项目搜索是显式提交、
有界查询，不持续扫描全部仓库。Git 比较只读 HEAD/磁盘/草稿，不隐式提交、暂存或回滚。

## 保存、冲突和恢复

本机安全编辑支持完整的 UTF-8、UTF-8 BOM、UTF-16 BOM 文本，默认原始文件上限 8 MiB；
保留可往返的编码/BOM/换行。语言服务另有更低的 2 MiB 单文件限制，不影响基础编辑。
旧执行端缺少版本保存协议时只读，不退回无基线的传输覆盖。

保存会校验用户、节点、工作区、窗口归属、控制权和原始字节版本；使用临时文件及原子替换。
保存后继续输入仍是未保存状态。保存全部逐文件报告，**不是跨文件事务**。
AWU 内部写者串行化；不合作外部程序仍可能在最后校验与替换之间写入，不能承诺全局 CAS。

遇到冲突，比较基线、磁盘和草稿，再显式应用合并；不自动覆盖任一版本。
保存超时先核对原回执，不重复点击无版本覆盖。权限不足、磁盘满、文件被删除或结果未知时保留草稿。
不要用同步上传绕过编辑冲突提示。

未保存文档在本机 IndexedDB 按身份隔离、有界保存。刷新后从草稿恢复入口的“本设备草稿恢复”面板恢复或导出；
恢复只填缓冲区，不自动保存。额度耗尽或存储禁用会提示持久恢复不可用，此时保持窗口并立即导出。
关闭脏文件可保存、明确放弃或取消；清理恢复记录前先导出。浏览器存储不是加密保险库。

远端文件在 Chat 和 Engine 中始终只读。先选择本机副本目录/离线空间，再点“下载到本机并打开”；
已有副本时，目录点击、快速打开和文件定位优先打开本机副本。右键“查看远端（只读）”可单独核对远端，
已有打开的远端标签不会被偷偷替换成本机来源。保存仅修改本机，要同步时显式选择“上传到执行端”。
旧远端草稿仍可从草稿恢复入口查看和导出，不能继续直接保存到远端。

“本机”离线副本与“执行端”是不同来源。Tauri 使用本机版本化原子替换，浏览器目录句柄使用
同源跨窗口锁和临时提交，托管副本使用 IndexedDB 事务。浏览器访问的执行端也属于远端；
只有桌面客户端的当前本机执行端保留直接编辑，文件完整性和权限保护仍然生效。
同名目录不等于同一个目录。权限撤销时重新获得用户选择后核对，不能自动提升权限。

下载的混合换行文本不再因 `mixed_eol` 被锁为只读。本机保存保留编码/BOM，
按原行保留 CRLF/LF/CR，新增行继承邻近换行风格，不整体统一换行。
二进制、损坏编码、超限或截断文件仍保护；操作系统只读权限也不会因下载而被绕过。

## 分离、合并与异常窗口

Chat 从上方 Session Tab 右键菜单使用“分离到独立窗口”与“合并回主窗口”，Engine 使用工具栏窗口图标。Web 必须由用户点击打开，弹窗被拦截时允许站点弹窗后重试；
源工作台不会消失。Web 不承诺桌面式跨窗口拖拽。Tauri 的 Chat 标签拖出/拖回及应用内显式按钮使用同一交接协议；
Engine 没有 Session 标签行，使用显式分离/合并按钮。原生顶部“会话”菜单已移除（需重建桌面客户端生效）。
原生交互待按[人工清单](engine-workbench-verification.md#人工核验清单)验证。

移动会先冻结新的发送、保存和终端输入，传递有界草稿、附件、编辑历史及资源引用，
目标 ACK 后提交归属，最后撤下源视图。窗口创建成功不等于移动成功；模型输出仍会继续。
Engine 分离提交后，原窗口恢复会话导航，目标窗口维持单工程；未确认的交接不会提前解除隔离。
从列表再次选择已分离会话只聚焦所属窗口，不复制可写会话。
工具待确认事项重新从执行端读取，不自动批准；一次性委托开关不复制。

故障处理：

1. 显示待确认时，点“核对窗口归属”，不要反复分离或发送相同消息。
2. 未完成交接可“继续原交接”或明确“取消原交接”；操作沿用原身份，不重放命令。
3. 刷新发现可靠交接包时，先“恢复最后交接状态”。只读核对不会越过本地恢复保护。
4. 主窗口不在时，保留子窗口，从 Chat 的 Session Tab 右键菜单（Engine 为“窗口与布局”···）→“交接恢复包”导出。浏览器关闭按钮不能保证异步合并，优先该菜单中的“安全合并并关闭”。
5. 旧窗口确已无法使用时才“显式收回视图归属”；旧窗口写入会被新代次拒绝，但这不停止后台进程，
   也不能恢复旧窗口尚未交接的新输入。

主窗口隐藏到托盘与真正退出不同。退出整个桌面应用会影响本机执行端、模型、终端和语言服务，
提示中列出窗口已报告的未保存文件、待核对保存及资源数量（跨窗口可能重复，未报告的状态未知），可以取消。

正常归属核对完成后不再占据提示行，结果可在 Chat 标签菜单或 Engine“窗口与布局”查看；失败、进行中、归属未知及待恢复草稿仍显示操作提示。
常用“合并回主窗口”仅移动工作台，菜单内“安全合并并关闭”会在交接确认后关闭独立窗口。

## 配置 Java / Python / Vue / React 语义服务

工程语义绑定执行端文件，不能把下载副本冒充远端缓冲区。下载副本目前提供基础编辑和语法高亮，
不自动上传草稿给远端 LSP；远端只读视图不开放格式化/重命名。以下语义编辑能力用于可写的本机执行端工程。
远端只读是编辑器的来源规则，不禁止用户明确授权的 Agent、终端或手动传输操作。

所有路径都是 **Session 执行节点** 上的路径。点击顶部“工程语言服务”图标，选择提供器并填写路径，
点“检查依赖并生成启用计划”，核对节点、工作区、版本和副作用，再单独勾选信任并启用。
`initializing` 不是 `ready`。应用不自动安装、联网补齐依赖、切节点或重启失败服务。

| 提供器 | 需要显式选择 |
| --- | --- |
| Java | JDT LS 1.42.0；运行 Java 21；项目 JDK；可选预装 Gradle 或预备 Maven 离线仓库 |
| Python | Node；固定工具 node_modules；项目/虚拟环境 Python；Ruff 0.11.13 |
| React | Node；typescript-language-server 4.3.3 / Prettier 3.5.3 工具目录；TypeScript 5.7.3 包目录 |
| Vue | Node；Vue language-server / typescript-plugin 2.2.12、Volar 2.4.15、Prettier 3.5.3；TypeScript 5.7.3 |

依赖准备、许可证、哈希与实际语义记录见[提供器矩阵](engine-provider-matrix.md)。
Java 的运行 JDK 与项目 JDK 不相同；Maven/Gradle 导入默认关闭，需要额外允许项目构建代码执行。
Maven 使用隔离离线 settings，不读取用户凭据；Gradle 禁用 wrapper。缺离线缓存报错，不改为联网下载。
格式化不执行项目 Prettier JS 配置/EditorConfig，也不自动安装插件。

补全、定义、引用和诊断使用未保存文本与版本映射。旧诊断不覆盖新文本；没有问题列表不等于工程编译通过。
格式化只修改可撤销草稿；跨文件重命名先预览，整体核对版本后应用草稿，再分别保存。
不支持的资源操作、越界目标或过时计划整份拒绝。每服务最多 32 个打开文档、总文本 16 MiB、16 个在途请求；
关闭文件会版本化释放语义缓冲区，不停止服务。换解释器/运行时需要先停止并确认旧实例退出，再重新启用。

当前四类提供器均保守按“可能写工作区”登记；这不是 OS 沙箱。
只有未来经过单独验证的只读提供器才可以不占写活动；已得到的只读诊断展示本身不启动进程、不占新活动。

## 交互终端与 LOOP

展开终端不会启动 Shell。点“创建终端”后核对实际节点、Shell、目录及权限；
Windows 使用 ConPTY（CMD `/D`、PowerShell `-NoProfile`），Linux x86_64 使用真实 PTY
（Bash `--noprofile --norc` 或 sh）。支持边界见[终端实测记录](engine-terminal-prototype.md)。
Shell 拥有执行端 OS 用户的实际权限，可 `cd` 到该用户有权访问的位置；不是模型原生沙箱，不自动提权。

多行粘贴先检查、可取消；聊天或文件里的命令不会自动运行。Ctrl+C 中断前台程序，**不代表 Shell 已退出**。
关闭区域、切 Chat、移动窗口只隐藏/重新订阅；停止请使用“停止所属进程树”，以 `exitConfirmed` 为准。
停止未确认时保护继续存在，不能通过关闭界面强行消除。

每终端保留尾部最多 2 MiB，读取每帧最多 128 KiB，整个管理器缓存上限 32 MiB。
历史缺口会标记，不能视为完整日志。输入在提交前消费序号，未知输入不自动重发；
后端重启不按旧 PID 接管或重跑命令。输出中的 OSC 剪贴板/链接等动作被拦截，应用不额外记录输入和环境。

LOOP 自动控制期间禁止新的工程写活动。人工接管后，保存、存活终端（即使空闲）和当前语言服务阻塞交还。
提示会定位具体活动，并可单独停止终端/服务；确认退出后再点交还。停止活动不会自动交还。
纯草稿只提示，不自动保存/丢弃。手动测试成功不会修复模型原生环境记录、消费旧队列或开启 Auto。
接管/交还成功且目标界面就绪后，顶部结果条自动移除、不留占位；历史检查点不可用或 Auto 关闭不会常驻占用空间。
处理中、结果待确认、加载失败及当前工程阻塞仍显示处理入口；移除结果条不删除回执，也不改变控制权或运行状态。

## 安全回退

先导出重要草稿和交接恢复包，核对未知保存，再显式停止工程进程并确认退出。
回到 Chat 只改变布局，不删除文件、不停止资源、不回滚 LOOP。安装旧版本前保留导出文件；
旧版不一定能读取新草稿格式。此次改动没有发布、部署或自动归档。
